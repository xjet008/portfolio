// intro

        
I started my crypto and Web3 journey back in 2019. BCH was the first thing I touched — not because I wanted to be a trader, but because I was curious and wanted to see how all of this worked.

        
Trading never really stuck. Charts bore me. I waste more time scrolling, poking at Linux, or reading docs than I do looking at a candle.

        
Later I started mining different coins like Monero, Cardano, and a few others — mostly for fun, and to learn how mining actually works. From there I slowly got deeper into Web3 and started exploring different projects and ecosystems.

        
I participated in projects like Monad, Movement, Story Protocol, Xion, 0G Labs, ZetaChain, Omni Network, Plume, and a lot of other L1s and L2s whose names I probably don’t even remember anymore.

        
I’ve run verifier and validator nodes on pretty much every kind of hardware I could get my hands on. Old PCs, laptops, dedicated machines, servers, shared setups — if I had access to the hardware, I probably tried running something on it.

        
Most of this was done on Linux. Servers, configs, storage, networking, docs open in another window. Quiet work, mostly in Discord. I’m not the type to post everything on CT.

        
Mining, nodes, hardware, infrastructure, L1s and L2s. Curiosity first. Hands dirty. Watching from the outside was never enough.
